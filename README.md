# Asystent Remontu — dokumenty publiczne

Repozytorium hostuje politykę prywatności i regulamin aplikacji mobilnej **Asystent Remontu**, publikowanej w Google Play i App Store.

## Strony

- **Strona główna:** https://jakatora.github.io/asystent-remontu-privacy/
- **Polityka prywatności:** https://jakatora.github.io/asystent-remontu-privacy/privacy.html
- **Regulamin:** https://jakatora.github.io/asystent-remontu-privacy/terms.html

## Aktualizacja

Wszystkie strony są statycznymi plikami HTML. Aby zaktualizować:

1. Edytuj odpowiedni plik HTML.
2. Aktualizuj datę „Data wejścia w życie" na górze dokumentu.
3. `git commit && git push` — GitHub Pages automatycznie republikuje.
